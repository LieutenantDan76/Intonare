Apple (WWDC25 · HIG Materials)
  • Lensing bends light; old materials scattered it. Grain = scatter dirt. Out.
  • Glass = nav layer. Content = standard materials. No glass-on-glass.
  • Larger = thicker (deeper shadow, softer scatter). Menus/sidebars get ambient spill.
  • Adaptive shadow / scroll-edge dissolve / interactive light flex.
  • Clear glass only over rich media + dimming — not exercise cards.
Ultra = farthest shippable polish (CSS)
  • Flush tab bar (not floating island). Selected = fill pill + hairline bar.
  • Fresnel rim + specular streak + top sheen on cards (optional Glassier).
  • Contact → far shadow stack, hue-tinted. Ambient spill optional.
  • Primary CTA tinted through light. Press energize. Concentric radii.
Cards — busy or not?
  • Apple’s rule: content stays standard material. Quiet = near-opaque + light lift.
  • Lifted = slight translucency so stage tint bleeds (Apple baseline card).
  • Glassier = Ultra optics. Can feel busy if every exercise card does it.
  • Recommendation if you like Apple tab: Quiet or Lifted cards, glass only on chrome.
