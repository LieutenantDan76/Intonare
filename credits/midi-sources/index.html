Adapted performance MIDI

Source files for Performance mode in Intonare.

These twenty-one sequences are adaptations of MIDI recordings by Bernd Krüger, published at piano-midi.de under the Creative Commons Attribution-ShareAlike 3.0 Germany licence.

That licence is ShareAlike, so the adapted files are published here under the same terms. Everything you hear in the app is his playing; the changes below are structural. The compositions themselves are public domain.

What was changed

  • Tempo map flattened. Every file sits at a fixed 120 BPM, 480 ticks per quarter, with the rubato baked into the absolute note positions. Playback is identical; the bar lines no longer line up with the score.
  • Tracks merged. Left and right hand are collapsed onto one track, channel 1, so the hand split is gone.
  • Velocities round-tripped through a 0 to 1 float, so a velocity may land a step either side of the original.
  • Pedal reduced to on and off (CC64 at 0 or 127). Half-pedalling is not preserved.
  • No trimming. Each file is the complete performance.

Seven pieces also appear in the app with a Rhodes voice. Those reuse the same note data with the pedal removed, so they are not listed separately.
